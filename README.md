# 🧮 CalculateAnything

> **One platform for all your everyday calculations.**

**CalculateAnything** is a modern, user-friendly web application designed to provide multiple useful calculators in one place. From academic calculations like **CGPA to Percentage** and **CGPA to SGPA** to financial and project-management calculations like **Simple Interest, Compound Interest, PERT and CPM**, CalculateAnything makes complex calculations quick and easy.

---

## 🚀 Features

### 🎓 Academic Calculators
- **CGPA to Percentage**
- **CGPA to SGPA**
- Quick and easy academic calculations
- Simple input-based interface

### 💰 Financial Calculators
- **Simple Interest Calculator**
- **Compound Interest Calculator**
- Calculate interest and final amount instantly

### 📊 Project Management Calculators
- **PERT Calculator**
- **CPM Calculator**
- Calculate project completion estimates
- Analyze task durations and critical paths

### ⚡ General Features
- Clean and responsive UI
- Fast calculations
- Easy-to-use interface
- Mobile-friendly design
- Multiple calculators in one application
- Interactive charts/visualizations where applicable
- Client-side calculations for fast results

## 💻 Getting Started

Follow these steps to run CalculateAnything locally.

### 1. Clone the Repository

```bash
git clone https://github.com/aamoddwivedi/CalculateAnything.git
```

### 2. Navigate to the Project

```bash
cd CalculateAnything
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal, typically:

```text
http://localhost:5173
```

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 🎯 Why CalculateAnything?

Calculations are often spread across different websites and applications. CalculateAnything brings commonly used calculations together into a **single, simple and accessible platform**.

The main goal of the project is:

> **Enter your values → Select the calculation → Get the result instantly.**
